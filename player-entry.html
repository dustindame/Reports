How To & FAQ
How do I log a pick?
Search the player, tap the winning team, set the price, then slide to confirm. It shows up live on the Draft Board and Team Picks instantly.
How do I undo a pick?
Find it in the "All Picks" list below and tap the ✕ next to it.
What's the commissioner PIN for?
It's set when the league is created and protects every write — logging picks, starting a break, marking the draft complete, changing settings. Sharing the league code alone lets people view the board, not edit it.
Can more than one person enter picks?
Yes — anyone with the league code and PIN can open Bid Board on their own phone and log picks, at the same time as you if you want. The same player can never be drafted twice, even if two people enter it around the same moment — the second attempt is automatically rejected. Handy for splitting up entry duty or handing it off if you need to step away.
Will changing a setting mid-draft mess up my picks?
No. Team count, budget, and roster positions lock automatically once any pick is logged, since changing those would scramble what's already been drafted — but everything else (board name, display toggles, Fun Extras) can still be changed anytime, and your picks are never touched.
If I'm Pro, does everyone else get Pro features too?
Yes — Pro belongs to the league, not your phone. Once a league is upgraded, anyone with its code and PIN gets full Pro access from their own device, even if they never bought Pro themselves — so handing Bid Board off to someone else (or letting a friend export the CSV from Team Picks) just works, no re-purchase needed.
What does Break do?
Switches the Draft Board (Pro feature) to a trivia/stat-leaders/odds screen for everyone watching — handy for a real pause in the draft.
What does Complete do, and why would I use it early?
Marking a draft complete unlocks the Recap page even if some roster slots never got filled — some drafts end early. You can reopen it later from the same button if needed.
Will my league ever get deleted?
Free-tier leagues are cleared out automatically after 7 idle days if the draft's still unfinished, or 14 idle days once it's complete — this keeps old one-off drafts from piling up. Pro leagues last much longer — 60 idle days — since a draft doesn't need to stick around forever once it's been copied into your actual fantasy service. Everything goes, including the Recap page and its stats/roast — download it first if you want to keep it.
How do people join or follow along?
Scan the QR code on the Draft Board, or open Team Picks and enter the league code — no PIN needed just to watch.
⚠️
Go to Settings?

The draft has already started — team count, budget, and roster positions are locked there now and your picks are safe either way. Everything else (board name, display toggles, Fun Extras) can still be changed freely.
